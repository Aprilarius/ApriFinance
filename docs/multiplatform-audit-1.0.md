# Проверка ApriFinance 1.0, сборка 20

15 ноября 2026. Выпуск для личной проверки Windows, Android и macOS.

## Исправления

- Обмен включает настройки анализа, цели, долги, метки, алиасы и подтверждения серий вместе с финансами и документами.
- Независимые параметры объединяются по ключам, цели и долги — по ID. Разные правки одной записи и удаление против правки требуют выбора версии. Дата и подпись подтверждённого периода объединяются вместе.
- Правка анализа во время отправки не теряется и не подтверждается устаревшим снимком. Изменения только настроек запускают автоматический обмен без повторной отправки принятой версии.
- Дата подтверждения внешней резервной копии и настройки системных напоминаний остаются на устройстве.
- При объединении проверяются и полный, и текущий остаток архивируемого счёта: будущий доход не скрывает ненулевой остаток сегодня.
- RPC v2 отклоняет записи старого клиента, который не переносит данные анализа.
- macOS использует публичное имя ApriFinance; прежний bundle ID сохранён. Проверено корректное поведение инициализации уведомлений без запроса разрешения при старте.
- Упаковщик Windows находит полный x64 CRT в разных версиях Visual Studio. Подписи Microsoft проверяются перед включением DLL; отсутствующая библиотека не подменяется случайным файлом.

## Границы проверки

Физические Android и Mac пользователя не подключались. Настоящий вход приложения в облако и обмен между тремя физическими устройствами ещё нужно проверить. SQL-проверка с ролями не заменяет эту проверку HTTP и авторизации. Системные напоминания зависят от разрешений и ограничений конкретной ОС.

Отдельный lint исходников зависимости flutter_local_notifications 22.0.0 выдаёт три MissingPermission и предупреждения; app lint проходит. Приложение проверяет разрешения и отключённый канал до планирования, отказ не выдаётся за успешно включённые напоминания. Отзыв разрешения и показ уведомлений следует проверить на телефоне.

APK в GitHub — debug preview для личной установки. Ключ CI отличается от прежних локальных APK; перед заменой сохраните .mfin. Удаление прежнего Android-приложения может потребоваться из-за различия подписей. QA release APK с отдельным тестовым ключом не публикуется. Mac имеет ad hoc подпись без Developer ID и нотарификации Apple. Windows EXE пока без подписи издателя.

Автоматический обмен работает только при открытом приложении в разблокированной текущей сессии. Пароли и сессия не сохраняются на диск; после перезапуска или истечения сессии нужен повторный вход. Передаётся целая зашифрованная база, поэтому вложения увеличивают трафик. Шифрование локальной SQLite и смена пароля существующей облачной копии в этот выпуск не входят.

## Проверка на личных устройствах

1. Сохраните .mfin прежней базы и пароль отдельно. Установите сборку 20 на все устройства.
2. Откройте **Настройки → Открыть облачный обмен**. Используйте один проект Supabase, аккаунт приложения и пароль зашифрованной копии. Публичный publishable/anon ключ не является паролем базы. Инструкция: [личное облако](../cloud/README.ru.md).
3. Сначала проверьте вымышленные операции и PDF на пустых базах. Сравните остатки, документы, цели и долги.
4. Выключите домашний ПК. Внесите независимые изменения на телефоне и Mac, выполните обмен, затем включите ПК и проверьте одинаковый результат без дублей.
5. Измените одну запись на двух устройствах без обмена. Убедитесь, что приложение предлагает выбор и сохраняет защитную копию. Отдельно проверьте разрешения напоминаний на Android и Mac.
