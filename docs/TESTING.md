# Проверка Windows

scripts/verify.ps1 проверяет закреплённые зависимости, форматирование, статический анализ и все unit/widget-тесты.

scripts/test-windows.ps1 запускает пять нативных сценариев: локальные операции и чеки, подтверждённые серии, настройки долга и восстановление, основной поток журнала и защиту от второго экземпляра. Во время тестов применяется отдельный mutex и временная SQLite. Не запускайте один и тот же нативный сценарий параллельно с собой.

Данные тестов вымышленные. Визуальные эталоны используют фиксированную дату. Тесты изменения сумм проверяют факт, переводы, связанные возвраты, будущие даты и целочисленные пределы. Подтверждения полноты и метки теряют силу после изменения источников.

installer/windows/nsis/test-installer.ps1 проверяет QA-пакет под отдельной регистрацией. Для проверки миграции ему передаётся прежний QA-установщик, а также отдельные каталоги WorkDirectory и FixtureDirectory. Фикстуру можно создать командой dart run installer/windows/tests/create_fixture.dart <new-directory>. Используйте QA-сборку установщика с параметром -InstallerQA.

Изменение эталона допустимо после просмотра отличий. Повторный flutter test должен проходить без --update-goldens.
