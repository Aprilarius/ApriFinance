ApriFinance 1.0, сборка 21 — упрощённое подключение и защищённое сохранение входа.

- Проект подключения уже указан в приложении; URL и публичный ключ находятся в дополнительных настройках.
- На каждом устройстве один раз войдите по email и паролю, затем один раз откройте зашифрованную копию её паролем. Для существующей копии нужен прежний пароль. Сохраните его отдельно для новых устройств.
- Сессия и пароль копии сохраняются в системном защищённом хранилище. Пароль аккаунта не сохраняется. Истекающие токены обновляются автоматически; отзыв доступа требует повторного входа.
- Синхронизация запускается при изменениях и возвращении в приложение. Конфликты требуют явного решения. Финансы доступны без сети.
- «Выйти и забыть подключение» удаляет сохранённый вход с этого устройства, сохраняя финансовые записи.

Windows: NSIS-установщик, Windows 10 x64 19041+. Android: подписанный release APK для ARM64, Android 7.0+; отладка отключена. Без настроенных приватных секретов подписи CI использует временный сертификат preview: он отличается от предыдущих APK. Перед заменой сохраните .mfin; Android может потребовать удалить старую установку. Приватный ключ подписи не входит в исходники или выпуск.

Mac: универсальный ZIP для Intel и Apple Silicon, macOS 12+. Ad hoc подпись без Developer ID и нотарификации Apple. Системное хранилище может потребовать разрешение доступа; при его отказе подключение не сохраняется в открытом виде.

Установите сборку 21 на устройства, где нужно запоминание входа. Формат финансовой копии и RPC v2 совместимы со сборкой 20. Первый реальный обмен на физических устройствах проверьте на вымышленных записях.
