Личный тестовый выпуск ApriFinance 1.0, сборка 20.

**Windows:** NSIS-установщик для Windows 10 x64 (19041+) и новее. Обновление сохраняет прежний каталог данных. Закройте приложение перед установкой; файл пока без подписи издателя.

- Облачный обмен переносит операции, счета, лимиты, платежи, покупки и документы, цели, долги и настройки анализа.
- Независимые изменения объединяются; конфликтующие правки требуют выбора версии с сохранением защитной копии.
- Все устройства обращаются к личному Supabase напрямую. Домашний ПК может быть выключен.
- Настройка проекта: [cloud/README.ru.md](../cloud/README.ru.md). Нужна актуальная схема RPC v2; обновите все устройства до сборки 20.

**Android:** APK для arm64, Android 7.0/API 24 и новее. Это debug-подпись для личной проверки. Ключ CI отличается от прежних локальных тестовых APK: перед заменой сохраните .mfin; Android может потребовать удалить прежнее приложение. Пароль .mfin сохраните отдельно.

**macOS:** ZIP с ApriFinance.app, macOS 12 и новее. Точная архитектура указана в имени архива. Приложение имеет ad hoc подпись, без Developer ID и нотарификации Apple; обычная установка может потребовать подписанного выпуска. Проверка на личном Mac остаётся обязательной.

Вход и пароль копии вводятся после запуска приложения; секретов и личных баз в выпуске нет. Автоматический обмен действует только в разблокированной текущей сессии при открытом приложении. Первая проверка — на вымышленных данных, затем перенос с выключенным ПК и проверка документов, сумм и напоминаний на физических устройствах.
