# Установщик Windows

Основной путь: scripts/build-windows.ps1 -Compiler <path-to-makensis.exe>. Используется NSIS 3.13 и готовая Windows release-сборка. Visual C++ Runtime копируется из установленного Visual Studio Redistributable либо из явно переданного RuntimeDirectory; подписи Microsoft проверяются.

Установка для текущего пользователя. Внутренняя версия содержит номер сборки и блокирует понижение версии. Старые пути данных и имена mutex сохраняются для совместимости. Удаление затрагивает только перечисленные файлы программы и собственные ярлыки, а неизвестные вложенные файлы сохраняет.

Установщик проверяет, что приложение закрыто, целевой каталог не содержит finance.sqlite, версия EXE соответствует pubspec и скомпилированный Dart payload не старше исходников. Установщик и EXE пока без подписи издателя. Системное хранилище сертификатов не меняется.
